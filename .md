npx vercel --prod --yes

Run the database and backend first, then the client. The client proxies /api to the backend on port 4000, and the backend needs Postgres.

From d:\udm-alumni:

Install dependencies (once):


npm --prefix backend install
npm --prefix client install
Configure the backend (once): copy backend/.env.example to backend/.env. The defaults work locally: DATABASE_URL points at localhost:5433, and MAIL_DRIVER=console prints reset links and codes to the backend terminal.

Start Postgres 16. npm --prefix backend run db:local runs scripts/local-db.js. I haven't opened that script, so check it first. If it doesn't start a database on port 5433, run Postgres 16 yourself, for example in Docker.

Create the schema and seed it (once):


npm --prefix backend run migrate
npm --prefix backend run seed:lookups
npm --prefix backend run seed:demo   # LOCAL ONLY: never run this against the production database
The migrate script may need up as an argument (npm --prefix backend run migrate -- up). The demo seed creates the demo accounts and a few hundred alumni.

Start the backend in one terminal: npm --prefix backend run dev (API on :4000).

Start the client in a second terminal: npm --prefix client run dev (Vite, at http://localhost:5173).
