# Web App Redesign Instructions

## Objective
Redesign the web application based on the provided `.dc.html` file.

## Important Instructions
- Follow the reference design as closely as possible.
- Do not change existing features or functionality unless explicitly instructed.
- Preserve all pages, role-based portals, forms, buttons, navigation, and interactions.
- Keep the existing backend, database structure, API integrations, and business logic unchanged.
- Do not add new features or modify unrelated sections.
- Ensure all existing functionality continues to work after the redesign.

## Goal
Match the `.dc.html` reference design while preserving the existing application and its functionality. Only implement explicitly requested changes or modifications necessary to reproduce the reference design.
